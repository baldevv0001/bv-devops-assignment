A NetworkPolicy restricts this workload to DNS egress only, and permits the
metrics port only from the monitoring namespace. Enforcement requires a CNI
that implements NetworkPolicy — Amazon VPC CNI, Calico and recent kindnet all
do. Confirm the metrics rule is actually being enforced with:

    kubectl run probe --rm -i --image=curlimages/curl:8.19.0 -n default --restart=Never \

return metrics.
